# GEO 工作台

生成式引擎优化（GEO）的内容生产与多平台发布控制台。Node 实现，默认端口 8030。

## 它做什么

- 按行业与关键词组织选题
- 生成草稿并保留来源与边界段
- 人工审核后才进入发布队列
- 发布结果回读，失败保留现场不重试

## 启动

```bash
node server.mjs
```

然后打开 `http://127.0.0.1:8030`。

## 边界

搜索建议是选题信号，不等于搜索量或付费需求。未审核的稿件不会自动发布；预览不等于上线。
